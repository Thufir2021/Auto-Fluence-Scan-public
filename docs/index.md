# FluenceScan Handbuch

FluenceScan bestimmt die laserinduzierte Zerstörschwelle (Fluenzschwelle,
single-shot und multi-pulse) aus Bildstapeln bestrahlter Oberflächen - nach
der D²-Methode von Liu (1982).

## Aufbau dieses Handbuchs

Die Kapitel folgen dem tatsächlichen Ablauf einer Auswertung, nicht der
Reihenfolge der Menüs in der Menüleiste:

| Kapitel | Inhalt |
|---|---|
| [1. Installation](installation.md) | Installations-Assistent, Voraussetzungen, Erststart |
| [2. Analyse starten](analyse-starten.md) | Bildstapel/Energien laden -> Verarbeiten/Segmentieren/Nachbessern -> Ergebnis -> Speichern & Contribute |
| [3. Zusatzfunktionen](zusatzfunktionen.md) | Proben-Anordnung, Histogramm & Profillinie |
| [4. Einstellungen](einstellungen.md) | Segmentierungsmodell, Contribute-Einstellung, Sprache |
| [5. Hilfe & Support](hilfe-support.md) | Support, Fehler melden, Kurzreferenz, Lizenz |
| [A. Anhang](anhang.md) | Die Physik dahinter |

!!! tip "Kurzreferenz in der App"
    Der Dialog **Hilfe > „Steuerung & Bedienung"** fasst die wichtigsten
    Handgriffe direkt in der App zusammen - dieses Handbuch hier ist die
    ausführliche Version davon, für alle Menüpunkte der App.
